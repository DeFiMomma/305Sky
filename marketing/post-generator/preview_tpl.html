Scheduling in Publer

Schedule the month in one sitting.

  1. Upload the media. In Publer, open Media Library and drag in the whole media folder from the kit (81 files). File names start with the post date, so they sort in order.
  2. Fill in the media links. Publer's CSV import needs a public link for each image. Publer's Media Library can copy the URLs of several files at once, comma separated. Copy each post's files and paste them into the Media URLs column of that row. media-checklist.csv lists which files go with which post, in order.
  3. Import one network at a time. Start Publer's bulk import from a CSV file, pick the Instagram account, and upload publer-instagram.csv. Repeat for Facebook and LinkedIn. Times are Eastern; set your Publer workspace to New York time.
  4. Check the special formats. The two Reels have Post subtype "reel". The three LinkedIn PDFs have subtype "pdf" and a title. If your Publer template uses different column names, copy our columns into Publer's blank template.
  5. Review the drafts in Publer's calendar, resolve the posts marked Confirm, then approve.

Prefer to skip the CSV? Create each post in Publer's composer, upload the files listed on its card, and paste the caption with the copy button. It takes about a minute per post.
